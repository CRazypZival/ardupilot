# XY-sub ArduSub飞控板

## 需求规格

### 引脚需求：STM32H743 lqfp 100
1. 16路电机输出: 不能使用N定时器
2. 三组I2C: 外接深度计；外接电源管理模块；板载气压计ICP20100+板载磁力计BMM150(共用一组I2C);
3. 一组USB 2.0
4. 两组串口：任意串口号即可
5. 一个引脚做IMU恒温控制
6. 一组SPI存储：使用W25Q128作为Flash
7. 一组SPI传感器：BMI088陀螺仪(BMI088_A_CS/BMI088_G_CS)
8. 一组SWD烧录口
9. 2个adc引脚：电压和电流引脚
10. 1个led指示灯
11. 不能有任何重复引脚
12. 不需要电源使能，其他未定义的不要设置
13. 两个电源保护检测引脚，低电平表示故障
